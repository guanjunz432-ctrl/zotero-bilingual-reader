# 可用于发布页的介绍

做了一个 Zotero 中英对照阅读插件，先开放 Windows / Zotero 9 测试版。

选中文献后，可以生成左侧英文原页、右侧中文排版的 PDF，尝试翻译图中的坐标轴、图例和流程框文字。处理按页缓存，失败页可补试，结果会加回原文献附件。

使用自己的 Codex 账户；页面内容交给云端处理，本机负责解析与排版，不安装本地模型。项目不提供共享账号或无限额度。

目前仍是早期版本。复杂图表、公式和小字需要对照原文核对，欢迎使用可公开的小样例反馈问题。安装步骤、数据流、已知限制和验证记录都放在仓库中。

发布时附本仓库和预览版 Release 链接。不要使用“完美保留”“零遗漏”“永久免费”“官方插件”等未获证据支持的宣传语。
