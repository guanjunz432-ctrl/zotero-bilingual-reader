# 已知限制

- 页面级模型分流是启发式；简单图表也可能由 Luna 完成。模型权限及可用性由账户和服务决定。
- 本版对斜排或极小图内标签保留原图并附页底对照，但无法可靠辨读的内容仍可能未翻译。
- 实测耗时来自单机少量样本；不承诺固定速度、额度节省比例或 OCR 完整率。

- 只发布 Windows / Zotero 9 预览版；尚未承诺 macOS、Linux 或其他 Zotero 版本。
- 对照按页面和文字区域排版，不保证中文与英文逐行等长。
- 图中文字依赖云端视觉识别。扫描质量、低对比度、竖排标签、曲线密集处可能识别或定位错误；翻译区域的覆盖可能触及邻近图形。
- 中文长度可能导致字号缩小，密集图例需放大阅读。
- 数字、否定、单位、公式及上下标需人工核对；结构校验通过并不证明翻译准确或无遗漏。
- 空白页、纯数学页、特殊旋转/裁切页和复杂表单尚未全面验证。
- 缓存依赖原文件哈希和排版版本；文件或算法版本变化可能重新消耗额度。
- 当前一次处理一个任务，无批量队列。每次生成新增附件，不自动清理旧版附件。
- 附件整理插件可能移动/重命名生成文件。可在其设置中按 `Codex中英对照_` 前缀排除；本项目不自动修改其他插件设置。
- 不提供云端服务、共享账号或无限额度；账户权限和网络错误可能中断翻译。
- 第一版使用 Windows 系统字体，不随项目再分发字体文件；缺字或缺少补充字体时需先修复环境。
